# Exordos CLI

Exordos CLI — это интерфейс командной строки для [платформы Exordos](https://github.com/infraguys/exordos_core). Он предоставляет унифицированный набор инструментов для управления полным жизненным циклом проектов Exordos — от сборки и выделения элементов до инициализации установок, управления резервными копиями и взаимодействия с работающей средой Exordos.

**📚 Документация платформы:** [exordos.github.io/exordos_core](https://exordos.github.io/exordos_core/)

С помощью одного бинарного файла вы можете:

- **Собирать проекты** — компилировать образы и артефакты проектов Exordos из декларативной конфигурации `exordos.yaml`.
- **Инициализировать установки** — запускать локальные виртуальные машины из собранных образов для разработки и тестирования.
- **Управлять установками** — подключаться по SSH, перечислять и удалять работающие экземпляры Exordos.
- **Взаимодействовать с платформой** — управлять элементами, IAM, секретами, вычислительными узлами, реалмами и многим другим с помощью расширенного набора подкоманд.
- **Автоматизировать резервное копирование** — выполнять периодическое или однократное резервное копирование установок со сжатием, шифрованием, ротацией и защитой от переполнения диска.

## Установка

### Бинарный файл (рекомендуется)

Установите CLI одной командой:

```bash
curl -fsSL https://repo.exordos.com/install.sh | sudo sh
```

### Через uv

```bash
uv tool install exordos
```

### Через pip

```bash
pip install exordos
```

---

Для базового использования (управление работающей платформой Exordos) дополнительные зависимости не требуются.

Если вы хотите **собирать элементы локально** (компилировать образы с помощью Packer и QEMU) или **инициализировать локальное развертывание платформы** (запустить локальную установку Exordos для разработки и тестирования), установите дополнительные зависимости, указанные ниже.

### Зависимости для локальной сборки

#### QEMU и libvirt (Ubuntu)

```bash
sudo apt update
sudo apt install qemu-kvm qemu-utils libvirt-daemon-system libvirt-dev mkisofs
sudo adduser $USER libvirt
sudo adduser $USER kvm
```

Возможно, потребуется выйти и войти снова в командную оболочку, чтобы изменения групп вступили в силу.

#### Packer

Скачайте [версию Packer 1.9.2](https://hashicorp-releases.yandexcloud.net/packer/1.9.2/) или более раннюю (из-за ограничений лицензирования) и поместите бинарный файл в `/usr/local/bin/` или любой другой каталог в вашем `$PATH`.

## Быстрый старт

Этот раздел охватывает основную цепочку операций: инициализацию проекта, сборку элемента, публикацию его в реестр и развертывание на работающей установке Exordos.

Для пошагового руководства с реальным примером см. [Руководство разработчика приложения](https://exordos.github.io/exordos_core/app-developer-guide/#quick-start) в документации платформы.

## Файл конфигурации Exordos

Каждый проект Exordos описывается файлом `exordos.yaml`. См. [справочник exordos.yaml](exordos-yaml.ru.md) для полного описания формата и примеров.

## Сборка проекта

Команда `exordos build` собирает элементы, определенные в `exordos.yaml`. Обязательным аргументом является путь к корневому каталогу проекта.

```sh
exordos build my_project
```

После успешной сборки выходные артефакты сохраняются в каталоге `output`. Для полного справочника см. [документацию по сборке](https://exordos.github.io/exordos_core/app-developer-guide/build/).
