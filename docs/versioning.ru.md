# Версионирование в платформе Exordos

Этот документ описывает стратегию версионирования, используемую в платформе Exordos, и то, как она реализована в пакете exordos.

## Обзор

Система версионирования в платформе Exordos следует принципам семантического версионирования с дополнительными улучшениями для отслеживания разработок и кандидатов на выпуск.

## Формат версии

Версии следуют этому формату:

```text
MAJOR.MINOR.PATCH-RC/DEV+DATE.COMMITHEXSHA[:8]
```

## Примеры

Релизная версия

```text
1.0.0
```

Разработческая версия

```text
0.0.1-dev+20250618190326.a1beab7c
```

Версия кандидата на выпуск

```text
0.4.1-rc+20260220064549.9223faa6
```

## Использование в exordos

```console
exordos get-version <ELEMENT_DIR>
```

Пример

```console
user@user ~ → exordos get-version /home/user/PycharmProjects/exordos/restalchemy
15.0.5-dev+20260407054854.672dcc2c
```
