# Резервные копии

Команда `backup` используется для резервного копирования текущей установки.

Базовый синтаксис команды `backup` следующий:

```bash
exordos backup -d /path/to/backup/directory
```

Это создаст резервную копию текущей установки в указанном каталоге. Команда создаст подкаталог для каждого домена и скопирует его диски в указанный каталог. Резервное копирование будет повторяться каждые 24 часа по умолчанию.

Чтобы настроить период резервного копирования, выполните следующую команду:

```bash
exordos backup -d /path/to/backup/directory -p 1h
```

Для однократного резервного копирования с выходом:

```bash
exordos backup -d /path/to/backup/directory -oneshot
```

## Базовое резервное копирование

Выполнять резервное копирование периодически всех доменов libvirt и сохранять их в текущем каталоге:

```bash
exordos backup
```

## Резервное копирование конкретного домена

Выполнять резервное копирование периодически конкретного домена libvirt и сохранять его в текущем каталоге:

```bash
exordos backup -n domain-name
```

## Исключить конкретные домены

Используйте `--exclude-name` (или `--no`) для пропуска конкретных доменов или шаблонов. `--name` и `--exclude-name/--no` не могут использоваться вместе.

```bash
exordos backup --exclude-name domain-foo --exclude-name domain-bar --exclude-name "domain-stand-*"
```

## Пользовательское периодическое резервное копирование

Выполнять резервное копирование периодически всех доменов libvirt и сохранять их в текущем каталоге:

```bash
exordos backup -p 1h
```

Доступные периоды: `1m`, `5m`, `15m`, `30m`, `1h`, `3h`, `6h`, `12h`, `1d`, `3d`, `7d`

## Одноразовое резервное копирование

Выполнить резервное копирование всех доменов libvirt один раз и сохранить их в текущем каталоге:

```bash
exordos backup -oneshot
```

## Сжатое резервное копирование

Выполнить резервное копирование всех доменов libvirt и сохранить сжатый архив в текущем каталоге:

```bash
exordos backup --compress
```

## Зашифрованное резервное копирование

Выполнить резервное копирование всех доменов libvirt и сохранить зашифрованный архив в текущем каталоге.

> ПРИМЕЧАНИЕ: Работает только с флагом `--compress`.

Установите переменные окружения `GEN_DEV_BACKUP_KEY` и `GEN_DEV_BACKUP_IV` для шифрования резервной копии. Ключ и IV должны быть больше или равны 6 байтам и меньше или равны 16 байтам.

```bash
export GEN_DEV_BACKUP_KEY=secret_key
export GEN_DEV_BACKUP_IV=secret_iv

exordos backup --compress --encrypt
```

Для расшифровки используйте команду `exordos backup-decrypt`:

```bash
exordos backup-decrypt backup.tar.gz.encrypted
```

## Восстановление резервных копий

Рассмотрим несколько сценариев восстановления конкретной машины из резервной копии. Резервная копия может быть зашифрованным архивом, архивом или каталогом. Поэтому первый шаг — преобразовать резервную копию в каталог:

Опциональная расшифровка резервной копии

```bash
exordos backup-decrypt backup.tar.gz.encrypted
```

Опциональное распаковка резервной копии

```bash
tar -xzf backup.tar.gz
```

Каталог резервной копии может содержать несколько подкаталогов для каждого домена. Рассмотрим следующий пример:

```sh
.
├── a4cb5e6e-domain-foo
│   └── domain.xml
│   └── f5e1a096-1093-4d80-a21b-d453281360d5_a4cb5e6e-1ef0-450b-b28c-9638fe6e7eb9.qcow2
├── 444b5183-domain-bar
│   └── domain.xml
│   └── 005ff0d3-3945-46d0-8704-27c645dfe3ab_444b5183-a049-4415-86c2-c3c8262c1403.qcow2
```

- `domain.xml` — файл конфигурации домена
- `*.qcow2` — образ диска

Наиболее частый случай использования — восстановление конкретного домена из резервной копии. Предположим, у нас уже есть работающий домен `foo`, но с поврежденным диском, и мы хотим восстановить его из резервной копии. Мы можем использовать следующие команды:

```bash
# Выключить домен
virsh shutdown foo

# Определить текущий путь к диску
sudo virsh domblklist foo

# Заменить диск
cp backup/a4cb5e6e-domain-foo/f5e1a096-1093-4d80-a21b-d453281360d5_a4cb5e6e-1ef0-450b-b28c-9638fe6e7eb9.qcow2 /var/lib/libvirt/images/foo.qcow2

# Запустить домен
virsh start foo
```

## Ротация

Для периодического резервного копирования можно установить количество сохраняемых резервных копий (номер ротации). Значение по умолчанию — 5. Используйте опцию `--rotate`:

```bash
exordos backup --rotate 10
```

## Предотвращение переполнения диска

Резервные копии могут занимать много места на диске, что может привести к падению всей системы, если диск заполнится. Чтобы предотвратить такую ситуацию, можно установить порог свободного места на диске. Если в процессе резервного копирования будет достигнут этот порог, процесс резервного копирования остановится. Используйте опцию `--min-free-space` для установки порога в ГБ.

```bash
exordos backup --min-free-space 50
```
