
# repo_upload

Upload element to repository

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos repo upload [OPTIONS] MANIFEST                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                           
```

## Options

* `repository` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `-r
--repository`

  Repository name or UUID to upload element to

* `manifest` (REQUIRED):
    * Type: Path
    * Default: `sentinel.unset`
    * Usage: `manifest`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
