
# exordos_network_borders_snat-del

Remove a SNAT rule (by source CIDR)

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos network borders snat-del [OPTIONS] BORDER SOURCE_CIDR                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                           
```

## Options

* `border` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `border`

* `source_cidr` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `source_cidr`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
