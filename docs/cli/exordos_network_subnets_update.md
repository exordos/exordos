
# exordos_network_subnets_update

Update a subnet or attach an existing subnet to a logical network

## Usage

```console

 Usage: exordos network subnets update [OPTIONS] SUBNET

```

## Options

* `subnet` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `subnet`

* `name`:
    * Type: text
    * Default: `none`
    * Usage: `--name`

* `network`:
    * Type: text
    * Default: `none`
    * Usage: `--network`

* `hypervisors`:
    * Type: uuid
    * Default: `sentinel.unset`
    * Usage: `--hypervisor`

* `gateway_file`:
    * Type: filename
    * Default: `none`
    * Usage: `--gateway-file`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
