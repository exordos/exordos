
# exordos_iam_permissions_role

List permissions bound to a role

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos iam permissions role [OPTIONS] ROLE                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                           
```

## Options

* `role` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `role`

  role name or uuid

* `output`:
    * Type: choice
    * Default: `table`
    * Usage: `--output
-o`

  the output format, defaults to table

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
