
# auth_enable-otp

Enable two-factor authentication

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos auth enable-otp [OPTIONS]                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                           
```

## Options

* `password`:
    * Type: text
    * Default: `none`
    * Usage: `-p
--password`

  Current password (optional, will be prompted if not provided)

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
