
# exordos_autocomplete_help

Display a autocomplete help

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos autocomplete_help [OPTIONS]                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                           
```

## Options

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
