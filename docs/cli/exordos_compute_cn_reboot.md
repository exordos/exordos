
# exordos_compute_cn_reboot

Reboot the node

## Usage

```console
                                                                                                                                                                                                                                                                                                            
 Usage: exordos compute cn reboot [OPTIONS] UUID_OR_NAME                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                            
```

## Options

* `uuid_or_name` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `uuid_or_name`

  node UUID or name

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
