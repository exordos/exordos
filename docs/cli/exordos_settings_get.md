
# exordos_settings_get

Get an individual value from a settings file

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos settings get [OPTIONS] KEY                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                           
```

## Options

* `key` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `key`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
