
# e_resources

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos e resources [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                           
```

    * Default: `false`
    * Usage: `--help`
