
# e_services

Manage services in the Exordos installation

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos e services [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                           
```

## Options

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
