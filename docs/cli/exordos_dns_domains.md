
# exordos_dns_domains

Manage domains in the Exordos installation

Use [`info`](exordos_dns_domains_info.md) (alias `i`) to show domain details and DNS records.

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos dns domains [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                           
```

## Options

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
