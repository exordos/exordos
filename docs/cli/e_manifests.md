
# e_manifests

Manage manifests in the Exordos installation

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos e manifests [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                           
```

## Options

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
