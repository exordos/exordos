
# exordos_build-inventory

Build elements inventory

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos build-inventory [OPTIONS] [PROJECT_DIR]                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                           
```

## Options

* `elements_dir`:
    * Type: path
    * Default: `.`
    * Usage: `-e
--elements-dir`

  Directory where elements are stored

* `project_dir`:
    * Type: path
    * Default: `.`
    * Usage: `project_dir`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
