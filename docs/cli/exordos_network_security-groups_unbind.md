
# exordos_network_security-groups_unbind

Unbind this group from a port

## Usage

```console

 Usage: exordos network security-groups unbind [OPTIONS] GROUP_REF PORT

```

## Options

* `group_ref` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `group_ref`

* `port` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `port`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
