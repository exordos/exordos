
# ee_edit

Edit manifest

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos ee edit [OPTIONS] UUID_NAME                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                           
```

## Options

* `uuid_name` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `uuid_name`

* `editor`:
    * Type: choice
    * Default: `nano`
    * Usage: `-e
--editor`

  Editor (nano or vim)

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
