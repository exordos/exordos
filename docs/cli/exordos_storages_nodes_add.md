
# exordos_storages_nodes_add

Create an OST resource for a registered agent to reconcile

## Usage

```console

 Usage: exordos storages nodes add [OPTIONS]

```

## Options

* `cluster` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `--cluster`

  Cluster name or UUID

* `agent` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `--agent`

  Registered universal agent name or UUID on the storage host

* `name` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `--name`

  Storage node resource name

* `uuid`:
    * Type: uuid
    * Default: `none`
    * Usage: `--uuid`

  Optional resource UUID; generated by core if omitted

* `location`:
    * Type: text
    * Default: `none`
    * Usage: `--location`

  Backing URI; defaults to file:///var/lib/rawstor/UUID

* `bind_address`:
    * Type: text
    * Default: `none`
    * Usage: `--bind`

  Bind IP:port; defaults to 0.0.0.0 and an unused port starting at 7777

* `endpoint`:
    * Type: text
    * Default: `none`
    * Usage: `--endpoint`

  Advertised ost://host:port; required for an OST on another host

* `failure_domain_path` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `--failure-domain-path`

  dc/row/rack/server; outer levels may be omitted

* `weight`:
    * Type: integer range
    * Default: `1`
    * Usage: `--weight`

* `description`:
    * Type: text
    * Default: ``
    * Usage: `--description`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
