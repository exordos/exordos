
# exordos_settings_repo_delete

Delete a repository from the settings file

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos settings repo delete [OPTIONS] REPO                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                           
```

## Options

* `repo` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `repo`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
