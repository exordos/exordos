
# exordos_iam_users_update

Update user

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos iam users update [OPTIONS] UUID                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                           
```

## Options

* `uuid` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `uuid`

* `name`:
    * Type: text
    * Default: `none`
    * Usage: `-n
--name`

  Username of the user

* `description`:
    * Type: text
    * Default: `none`
    * Usage: `-D
--description`

  Description of the user

* `first_name`:
    * Type: text
    * Default: `none`
    * Usage: `--first-name`

* `last_name`:
    * Type: text
    * Default: `none`
    * Usage: `--last-name`

* `surname`:
    * Type: text
    * Default: `none`
    * Usage: `--surname`

* `phone`:
    * Type: text
    * Default: `none`
    * Usage: `--phone`

* `email`:
    * Type: text
    * Default: `none`
    * Usage: `--email`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
