
# exordos_iam_idps_well-known

Show OpenID configuration (.well-known) of the idp

```console
                                                                                                                                                                                                                                                                                                            
 Usage: exordos iam idps well-known [OPTIONS] UUID                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                            
```

* `uuid` (REQUIRED):

    * Default: `sentinel.unset`
