
# exordos_em_manifests_uninstall

Uninstall manifest by UUID or name

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos em manifests uninstall [OPTIONS] UUID_OR_NAME                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                           
```

## Options

* `uuid_or_name` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `uuid_or_name`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
