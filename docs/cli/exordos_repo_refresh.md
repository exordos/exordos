
# exordos_repo_refresh

Refresh repository. Refresh all lazy repositories if not specified

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos repo refresh [OPTIONS] [NAME_OR_UUID]                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                           
```

## Options

* `name_or_uuid`:
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `name_or_uuid`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
