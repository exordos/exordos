
# iam_clients

Manage clients in the Exordos installation

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos iam clients [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                           
```

## Options

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
