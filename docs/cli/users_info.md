
# users_info

Show detailed information about the user

## Usage

```console
                                                                                
 Usage: exordos iam users info [OPTIONS] USER                                   
                                                                                
```

## Options

* `user` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `user`

  user UUID or username

* `output`:
    * Type: choice
    * Default: `table`
    * Usage: `--output
-o`

  the output format, defaults to table

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
