```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos realms pool [OPTIONS] NAME                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                           
```

## Options

* `name` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `name`

* `output`:
    * Type: choice
    * Default: `table`
    * Usage: `--output
-o`

    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
