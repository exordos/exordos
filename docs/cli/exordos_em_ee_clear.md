
# exordos_em_ee_clear

Uninstall all elements, except base

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos em ee clear [OPTIONS]                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                           
```

## Options

* `y`:
    * Type: boolean
    * Default: `false`
    * Usage: `--y
-y`

  Automatically answer yes for all questions

* `timeout`:
    * Type: float
    * Default: `600.0`
    * Usage: `--timeout`

  Seconds to wait for elements to be uninstalled

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
