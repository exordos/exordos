
# exordos_compute_sets_power-off

Power off the set

## Usage

```console
                                                                                                                                                                                                                                                                                                            
 Usage: exordos compute sets power-off [OPTIONS] UUID_OR_NAME                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                            
```

## Options

* `uuid_or_name` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `uuid_or_name`

  set UUID or name

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
