
# exordos_cn_info

Show detailed information about the node

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos cn info [OPTIONS] NODE                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                           
```

## Options

* `node` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `node`

  node UUID or name

* `output`:
    * Type: choice
    * Default: `table`
    * Usage: `--output
-o`

  the output format, defaults to table

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
