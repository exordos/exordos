
# exordos_dbaas

dbaas group in the Exordos installation

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos dbaas [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                           
```

## Options

* `dbaas_endpoint`:
    * Type: text
    * Default: `none`
    * Usage: `--dbaas-endpoint`

  Exordos dbaas API endpoint, defaults to the dbaas element behind the endpoint

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
