```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos elements clear [OPTIONS]                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                                           
```

## Options

* `y`:
    * Type: boolean
    * Default: `false`
    * Usage: `--y
-y`
