
# imports_list

List imports

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos em imports list [OPTIONS]                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                           
```

## Options

* `element`:
    * Type: text
    * Default: `none`
    * Usage: `-e
--element`

  Name or uuid of the element

* `output`:
    * Type: choice
    * Default: `table`
    * Usage: `--output
-o`

  the output format, defaults to table

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
