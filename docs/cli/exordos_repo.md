
# exordos_repo

Manage Exordos repository

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos repo [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                           
```

## Options

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
