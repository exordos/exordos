
# borders_forward-del

Remove a DNAT forward (by <tcp|udp>:<listen_port>)

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos network borders forward-del [OPTIONS] BORDER LISTEN                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                           
```

## Options

* `border` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `border`

* `listen` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `listen`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
