
# vs_profiles

Manage profiles in the Exordos installation

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos vs profiles [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                           
```

## Options

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
