# exordos_ee_manifest

Print the raw element manifest as YAML

## Usage

```console

 Usage: exordos ee manifest [OPTIONS] UUID_NAME

```

## Options

* `uuid_name` (REQUIRED):
    * Type: text
    * Default: None
    * Usage: `uuid_name`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
