
# exordos_network_networks_update

Update network metadata or its complete driver specification

## Usage

```console

 Usage: exordos network networks update [OPTIONS] NETWORK

```

## Options

* `network` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `network`

* `name`:
    * Type: text
    * Default: `none`
    * Usage: `--name`

* `description`:
    * Type: text
    * Default: `none`
    * Usage: `--description`

* `driver_spec_file`:
    * Type: filename
    * Default: `none`
    * Usage: `--driver-spec-file`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
