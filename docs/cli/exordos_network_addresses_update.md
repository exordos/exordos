
# exordos_network_addresses_update

Associate or disassociate a floating address

## Usage

```console

 Usage: exordos network addresses update [OPTIONS] ADDRESS

```

## Options

* `address` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `address`

* `port`:
    * Type: text
    * Default: `none`
    * Usage: `--port`

  Port to associate (UUID/name)

* `no_port`:
    * Type: boolean
    * Default: `false`
    * Usage: `--no-port`

  Disassociate from the port

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
