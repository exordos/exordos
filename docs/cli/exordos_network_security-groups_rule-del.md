
# exordos_network_security-groups_rule-del

Remove an allow rule from a group

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos network security-groups rule-del [OPTIONS] GROUP SPEC                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                           
```

## Options

* `group` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `group`

* `spec` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `spec`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
