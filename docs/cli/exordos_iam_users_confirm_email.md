
# exordos_iam_users_confirm_email

Confirm email of the user

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos iam users confirm_email [OPTIONS] USER                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                           
```

## Options

* `user` (REQUIRED):
    * Type: uuid
    * Default: `sentinel.unset`
    * Usage: `user`

  user UUID

* `force`:
    * Type: boolean
    * Default: `false`
    * Usage: `-f
--force`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
