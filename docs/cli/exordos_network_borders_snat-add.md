
# exordos_network_borders_snat-add

Add a SNAT rule to a border

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos network borders snat-add [OPTIONS] BORDER SPEC                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                           
```

## Options

* `border` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `border`

* `spec` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `spec`

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
